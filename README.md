# 🧮 Құрама есептерді шығару (Математикалық теңдеулер, 2-сынып)

Интерактивная веб-презентация для уроков математики во 2 классе на казахском языке.

**Сабақтың тақырыбы:** №47 сабақ. Құрама есептерді шығару. Қазақстанның көрікті жерлері. 1 – 8-тапсырмалар.  
**Сюжеттік ойын:** «Қазақстан бойынша тур-саяхат» 🎒

---

## 🌟 Слайдтар мазмұны

1. **Титулдық слайд:** «Құрама есептерді шығару. Қазақстанның көрікті жерлері» (CSS-пен салынған Бурабай таулары мен қарағайлы орман пейзажы).
2. **1-аялдама: Бурабай** (Көкшетау маржаны, 94-бет, 1-тапсырма): Балалар мен ересектердің демалысқа баруын есептеу.
3. **3-аялдама: Көлдер құпиясы** (Балқаш, Алакөл, Теңіз көлдері, 95-бет, 3-тапсырма): Көлдер тереңдігін екі амалмен табу.
4. **Викторина (1-бөлім):** Өрнектерді салыстыру және белгісізді табу (теңдеулер).  
   *Мүмкіндігі:* Сұрақ карточкасын басқанда — сұрақ жоғалып, орнына жауап пен толық түсіндірме шығады!
5. **Викторина (2-бөлім):** Гүлзар есебі, теңдеулер және өрнектер мәнін табу. Қайта бастау батырмасы.
